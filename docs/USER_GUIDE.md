# 智能水处理系统设计平台 - 使用指南

## 🚀 快速开始

### 环境要求

- Node.js 18+ 
- pnpm 9.0+
- 现代浏览器（Chrome 90+, Edge 90+, Firefox 88+）

### 安装依赖

```bash
# 安装全局工具（如果尚未安装）
npm install -g pnpm

# 进入项目目录
cd "g:\Water system\projects"

# 安装依赖
pnpm install
```

### 启动开发服务器

```bash
# 方式 1: 使用 coze dev（推荐）
coze dev

# 方式 2: 使用 pnpm 脚本
pnpm dev
```

访问 http://localhost:5000 查看应用

### 构建生产版本

```bash
# 构建
pnpm build

# 启动生产服务
pnpm start
```

## 📋 功能模块说明

### 1. 水质参数输入

**功能**: 输入或 AI 解析进出水水质参数

**支持的操作**:
- 📷 上传水质报告图片（AI 自动识别）
- 📝 粘贴文本报告（AI 解析）
- ⌨️ 手动输入 40+ 水质参数
- 🎯 设置目标出水水质
- 📊 查看进出水水质对比

**参数分类**:
- 基础理化指标（pH, TDS, 浊度，温度等）
- 阳离子（钙、镁、钠、钾等）
- 阴离子（氯离子、硫酸根、碳酸氢根等）
- 有机/生物指标（COD, BOD, 细菌总数等）
- 安全性指标（铁、锰、铝等）

**设计水量配置**:
- 产水量（m³/h）- 主输入
- 回收率（%）- 滑块调节
- 进水量 - 自动计算

### 2. 自定义工艺设计

**功能**: 自由配置水处理工艺流程

#### 快速预设

点击预设按钮快速配置：
- 💧 **简单 RO** - 仅反渗透
- 🏭 **完整预处理+RO** - 多介质 + 活性炭 + 软化 + 精滤 + RO
- 🔬 **UF+RO 双膜法** - 超滤 + 反渗透
- 🎯 **NF+RO 组合** - 纳滤 + 反渗透
- 📈 **两级 RO** - 一级 RO + 二级 RO

#### 工艺单元库

**预处理**:
- 🏺 多介质过滤器
- 🪵 活性炭过滤器
- 💎 离子交换软化器
- 🔍 精密过滤器（100μm ~ 0.22μm 可调）

**膜处理**:
- 🌊 超滤（UF）- DuPont SFP/SFD 系列
- 🎯 纳滤（NF）- Dow Filmtec NF 系列
- 💧 反渗透（RO）- Dow Filmtec BW/LE/SW 系列
- ⚡ EDI 电去离子

**消毒**:
- 💡 紫外消毒（UV）
- 🫧 臭氧消毒
- 💊 加药装置

#### 操作说明

1. **添加单元**: 从左侧选择工艺单元添加到流程
2. **配置参数**: 点击单元卡片配置详细参数
3. **调整顺序**: 拖拽单元调整工艺顺序
4. **删除单元**: 点击删除按钮移除单元
5. **过滤精度**: 精密过滤器支持 100μm ~ 0.22μm 精确调节
6. **膜型号选择**: 超滤/纳滤/反渗透支持型号选择

### 3. 水泵选型

**功能**: 智能推荐合适的水泵型号

#### 选型逻辑

**原水泵**:
- 根据进水量和所需扬程
- 南方泵业 CNP 产品库
- 考虑温度修正系数

**RO 高压泵**:
- 计算系统操作压力
- 考虑渗透压（范托夫公式）
- 浓水渗透压计算
- 污堵余量和管路损失

**段间增压泵**:
- 两段式 RO 系统
- TDS > 5000 mg/L 自动推荐
- 回收率 > 75% 自动推荐

**超滤产水泵**:
- 根据超滤系统配置
- 考虑跨膜压差

#### 并联泵配置

系统流量 > 50 m³/h 时自动推荐并联方案：
- 50-100 m³/h: 2 台泵
- 100-200 m³/h: 3-4 台泵
- > 200 m³/h: 按单台≤50 m³/h计算

### 4. 过滤效果 AI 模拟

**功能**: AI 模拟每个工艺单元的过滤效果

#### 模拟算法

基于水处理工程文献的精确计算模型：

**多介质过滤器** - 深度过滤模型
```
η = 1 - exp(-k × L × v^n)
去除率：浊度 50-80%, 悬浮物 70-90%
```

**活性炭过滤器** - Freundlich 吸附模型
```
q = K × C^(1/n)
去除率：COD 30-60%, 余氯 90-99%
```

**超滤膜** - 筛分机理 + LRV 对数去除率
```
LRV > 2 (99%+ 去除浊度和细菌)
出水 SDI < 3
```

**纳滤膜** - Donnan 效应 + 筛分
```
TDS 去除 30-60%
硬度去除 50-80%
```

**反渗透膜** - 溶解 - 扩散模型
```
J_w = A × (ΔP - Δπ)
TDS 去除 95-99%
```

#### 模拟结果

**展示内容**:
- 📊 每个单元的进出水水质对比
- 📈 去除率统计（TDS、浊度、COD）
- ✅ 目标达成评估
- ⚠️ 问题分析（如 RO 进水铁超标）
- 💡 改进建议

**污染风险评估**:
- 整体风险等级（低/中/高）
- 风险因素分析
- 预防建议

## 🔧 常见问题

### Q1: AI 解析失败怎么办？

**A**: 可以尝试以下方式：
1. 确保图片清晰、光线充足
2. 使用标准格式的水质报告
3. 手动输入关键参数（TDS、pH、浊度必填）

### Q2: 如何选择合适的膜型号？

**A**: 系统会根据 TDS 自动推荐：
- TDS < 1000 mg/L → 低压膜（LE 系列）
- 1000 < TDS < 10000 mg/L → 苦咸水膜（BW 系列）
- TDS > 10000 mg/L → 海水膜（SW 系列）

### Q3: 段间增压泵什么时候需要？

**A**: 满足以下任一条件时推荐：
- 进水 TDS > 5000 mg/L
- 回收率 > 75%
- 两段式 RO 系统且需要提高第二段压力

### Q4: 模拟结果显示"不达标"怎么办？

**A**: 查看分析报告中的建议：
1. 增加预处理单元（如多介质、活性炭）
2. 调整膜型号（更高脱盐率）
3. 增加 RO 段数
4. 添加第二级 RO

### Q5: 如何保存设计方案？

**A**: 目前支持：
1. 导出 TXT 报告（设计总结页面）
2. 浏览器截图
3. 复制设计参数到 Excel

（未来版本将支持云端保存）

## 📊 性能优化建议

### 处理大型系统

对于 > 100 m³/h 的大型系统：
1. 使用预设工艺流程
2. 减少不必要的工艺单元
3. 避免频繁切换步骤

如果浏览器变慢：
1. 刷新页面重新开始
2. 关闭其他浏览器标签页
3. 清除浏览器缓存
